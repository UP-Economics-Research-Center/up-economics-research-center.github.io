# Start here — Google Sites migration

1. Confirm the Center owner’s UP Google Workspace account; no Sites editor session is currently connected to this workspace.
2. In team-owned Google Drive, create “UP Economics Research Center — Website”. Create People and Brand subfolders. Upload all files from this package’s assets folder.
3. Open content-register.csv in Google Sheets. It has 12 people and nine research areas; every entry is unapproved until the Center owner verifies it.
4. Create a blank Google Site draft and follow docs/superpowers/plans/2026-09-24-google-sites-v1-migration.md. Use site-copy-pack.md for text.
5. Use homepage-concept.html and the other local pages as visual reference; do not import the HTML as a Google Sites page. Rebuild with native text/image/section blocks.
6. Keep the draft private until content, portrait permissions, public contact, domain and audience are approved.

YouTube campus film: https://www.youtube.com/watch?v=rjUKsJuxgVQ. Insert it with Google Sites → Insert → YouTube; use a native player.

This package contains no publication/event/news demo records. Google Sites cannot reproduce the mock’s JavaScript filters or page animations natively. See the build plan for archive/search choices and review steps.
