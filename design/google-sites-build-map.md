## Google Sites migration v1 — current source of truth

Google Sites is the chosen publishing platform. Build a native editable site with 16 pages: Home, Research hub + nine nested area pages, People, Publications, Seminars, News, About. The local HTML/CSS is visual reference; Google Sites does not import its custom code as native content. Use a team-owned Drive folder and register as the edit source.

Start with [the migration guide](google-sites-migration/START-HERE.md), [copy pack](google-sites-migration/site-copy-pack.md), [editorial register](google-sites-migration/content-register.csv), [detailed build plan](../docs/superpowers/plans/2026-09-24-google-sites-v1-migration.md), and [design brief](../docs/superpowers/specs/2026-09-24-google-sites-v1-migration-design.md).

Google Sites v1 uses native pages, themes, search, YouTube and Drive embeds. Archive publications by type/year; archive news by year; do not claim the local mock’s JavaScript filters, transitions or external Manrope font can be reproduced natively. No sample publication/event/news records should be copied to the Site.

The package includes all twelve source portraits. Source ownership and reuse permission still require Center approval before the public launch. Google Workspace Site editor access is not currently connected.
