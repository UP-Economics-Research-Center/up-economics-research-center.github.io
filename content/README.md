# Editorial content

Create and maintain records through `/admin/` after the organization owner configures the GitHub OAuth Worker and invites editors. Records are JSON files in the collection folders below. A record appears on the public site and in search only when its `published` field is `true`; check the facts before setting `published` to `true`. Saving the change commits directly to `main` and triggers a site deployment. The optional Reference URL may point to any supporting page or document; it need not be a personal website.

- `settings/site.json`: public site name, approved home-page copy, campus video, campus video metadata, optional featured-paper image, and footer note.
- `settings/about.json`: approved About-page scope, collaboration, and public contact.
- `people/`: approved researcher profiles. Add an optional Reference URL when a useful supporting page or document is available.
- `research-areas/`: approved topic labels, short `summary`, fuller `overview`, repeatable `projects` (ongoing or planned lines of work, with title, summary, and researcher names), links to researcher IDs, and an optional Reference URL.
- `publications/`: research outputs such as journal articles and working papers, with ordered authors, abstracts, year, type, venue, DOI/canonical link, topics, and optional approved PDF. These appear in paper lists, sorted newest year first.
