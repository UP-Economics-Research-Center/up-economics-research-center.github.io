Save a draft → Request review → Publish after approval

Saving a draft does not update the public website. Complete the English and Spanish fields, then move the entry to In review. Another editor must review and approve the change in GitHub before publication. Ready in the editor is a workflow status; it does not replace that approval.

The Include on website switch controls whether the approved record appears publicly. Keep it on when updating an existing public record; turn it off only to hide the record after publication.

Instrucciones en español

Guarda un borrador, completa ambos idiomas y cambia el estado a In review para solicitar revisión. Otra persona debe aprobar el cambio en GitHub antes de publicarlo. El estado Ready no sustituye esa aprobación. Mostrar en el sitio controla la visibilidad del registro después de aprobar y publicar; al editar un registro público, conserva el interruptor activado.
